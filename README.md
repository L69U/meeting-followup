# Meeting Follow-up / 会后跟进

面向外贸客户沟通的原生 iPhone App，目标为正式 App Store 发布。当前为开发中源码，不是已经上架或经过真机验证的成品。

## 第一版

语音备忘录保存到「文件」→ 导入音频 → 英文转录（可编辑、含时间点）→ 导出 TXT → 中文会议纪要 → 人工确认跟进任务。

已添加原始录音回听、时间点跳转、前后十秒跳转、纪要与跟进清单 TXT 导出。实现与验证状态见 `VERIFICATION.md`。

技术：SwiftUI / iOS 17+；本地 JSON 与音频文件；Python 标准库开发网关；Groq Whisper 转录及文本模型总结。API Key 仅在服务端环境变量中配置。

## 开发后端

在 `backend` 中运行 `python -m unittest discover -s tests -v`。

设置 `GROQ_API_KEY`、`APP_ACCESS_TOKEN`（至少 24 字符）后运行 `python server.py`。默认仅监听 `127.0.0.1:8787`。`SUMMARY_MODEL` 默认 `openai/gpt-oss-120b`，可配置。不要把密钥写进源码或分享截图。

此网关仅供单用户开发测试：正式上线仍需 HTTPS、独立用户认证、每用户配额、费用上限、任务队列、访问控制与隐私政策。免费 API 不等于无限公共服务。请求在内存中处理，不主动保存音频或文字、不输出正文日志；上游提供商会收到上传内容。

## iOS 构建

只有 Windows 的情况下，已准备手动触发的云端 Mac 构建方案，见 `CLOUD_BUILD.md`。尚未连接仓库或运行。

在 Mac 上安装 Xcode 与 XcodeGen，在 `ios` 中运行 `xcodegen generate`，打开生成的 `MeetingFollowup.xcodeproj`，配置自己的 Bundle ID 和签名 Team，选择模拟器或 iPhone 运行。

App 设置中填写自己的 HTTPS 网关地址和开发访问令牌（存储在 Keychain）。网关地址必须是实际可达的服务；尚未部署任何云服务。

## 已知边界 / 发布前验收

- Windows 环境未编译 Swift，必须通过 Xcode 构建、模拟器及真实 iPhone 验证。
- 未提供 Groq 凭据，真实转录、中文纪要质量尚未验证。
- 导入上限 500 MB、转录上限四小时；录音在设备端按五分钟分段转为 M4A，每段仍检查 24 MB 上传限制。已完成片段进度保存在本地，失败可继续；全部成功前不替换旧文字稿。转换、恢复和长音频准确度尚待真机验证。分段交界处需抽查有无断句或识别遗漏。
- 转录不自动识别人名；任务负责人和日期不推测，AI 任务需要确认。
- 当前转录是前台请求；退出 App 后不保证继续。正式版需要后台任务/恢复设计。
- `ios/Tests` 已加入数据兼容、恢复进度、纪要过期提示和导出状态测试；尚未运行，需要 Xcode 的 Test 操作。
- 不录制同一部 iPhone 上的微信/WhatsApp 通话。
- 还需要英文界面本地化、图标、无障碍、隐私与支持页面、App Store 文案截图、签名与真实发布审核。

## 完成标准

真实 iPhone 导入语音备忘录音频；双方英文、数字正确率人工抽查；错误可编辑；TXT 分享成功；中文纪要不虚构；任务可修改、完成；重启后记录存在；删除清除本地音频和记录；失败可重试；真实 App Store 审核通过并可下载。
